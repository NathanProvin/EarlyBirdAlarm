## Data safety form
- **Does the app collect or share user data?** No.
  - **Location** (approximate and precise): used only on the device — to pick the bird region ("Use my location"), and because Android requires it for the Bluetooth search of face-to-face trading. Never transmitted → not "collected" under Play's definition (processed ephemerally on device).
  - **Face-to-face trading:** the cards the user chooses to trade go directly from one phone to the other (Google Nearby Connections, Bluetooth / Wi-Fi). They are game items, not personal data; nothing goes to a server, to the developer or to a third party → not "shared" under Play's definition. A random, per-session name is used for pairing; no account, no identifier.
  - No personal info, no identifiers, no analytics, no crash reporting.
- **Is data encrypted in transit?** Yes (HTTPS downloads from GitHub Pages; Nearby Connections encrypts its connections).
- **Can users request deletion?** No data is collected; uninstalling removes everything. Android Auto Backup is handled by Google in the user's own account.

## Permission declarations
### Full-screen intent (`USE_FULL_SCREEN_INTENT`)
Core functionality: **alarm clock**. When an alarm the user set goes off, the app shows a full-screen quiz (identify the bird) that the user must answer to stop the alarm, including on the lock screen.

### Exact alarms (`USE_EXACT_ALARM`)
The app's core function is an **alarm clock**: users set alarms that must ring at the exact time they chose. `USE_EXACT_ALARM` is permitted for alarm clock apps.

### Foreground service (media playback)
Plays the alarm's bird recording while the alarm rings, until the user answers or snoozes.

### Location (`ACCESS_COARSE_LOCATION`, `ACCESS_FINE_LOCATION`) — foreground only
- Coarse: optional, only when the user taps "Use my location", to choose the bird region; processed on the device.
- Fine: only while the Trade screen is open — Google Nearby Connections requires precise location for its Bluetooth discovery. The position itself is never read or sent.
- No background location → no location declaration form is needed.

### Bluetooth and nearby devices (`BLUETOOTH_SCAN`, `BLUETOOTH_ADVERTISE`, `BLUETOOTH_CONNECT`, `NEARBY_WIFI_DEVICES`)
Asked only when the user opens Trade: to find and connect to the other player's phone for a face-to-face card trade.

## Content rating (IARC questionnaire)
No violence, sexual content, profanity or gambling (no purchases; boosters are free and timed). **User interaction:** answer "yes" to users exchanging content — players can trade in-game cards face to face with a nearby phone; there is no chat, no free text, no user profile and no online interaction. Card sharing is an image sent via the system share sheet. Expected rating: Everyone / PEGI 3 (possibly with an "Users interact" notice).
